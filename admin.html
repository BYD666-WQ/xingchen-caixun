需要一次性粘贴 GitHub fine-grained PAT。建 token 时选：
① Repository access: Only select repositories → BYD666-WQ/xingchen-caixun
② Permissions: Contents: Read and write（只给这一项；读用于取 sha）
③ Expiration: 90 天
token 只存本机 localStorage，不会上传本站；但同一浏览器其他 byd666-wq.github.io 页面也能读到，公用电脑用完点「清除本机 token」。

保存后 GitHub Pages 会自动重建；如 2 分钟后页面还是旧数据，刷新一次即可。
